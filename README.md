# Map Size Configurator

**Map Size Configurator** is a mod for **Zumbi Blocks 2** that adds a configurable scale for scaling the generated map's size from `0.5x` up to `2.0x`. By default, this mod scales the map size to `2.0x`.

## Installation

1. Make sure you have the latest version of **BepInEx 5** installed
2. Download the latest version of the mod from the [releases](https://github.com/tbv001/ZB2.MapSizeConfigurator/releases) page
3. Copy the DLL file into the `plugins` folder of your BepInEx installation:

```
Zumbi Blocks 2 Open Alpha\BepInEx\plugins\MapSizeConfigurator.dll
```

## Configuration

On first launch with the mod installed, a configuration file is generated at:

```
Zumbi Blocks 2 Open Alpha\BepInEx\config\com.theblackvoid.mapsizeconfigurator.cfg
```
